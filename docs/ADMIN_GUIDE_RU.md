# Руководство администратора: как добавлять материалы (простыми словами)

Для тех, кто наполняет платформу уроками. Всё делается в разделе **Админ-панель → Материалы**. Ничего не нужно настраивать на сервере.

## Самый простой способ: загрузить много файлов сразу

1. **Админ-панель → Материалы → «Массовая загрузка»**.
2. Выберите **Предмет** (и, если нужно, **Тему**). Видимость оставьте **«Черновик»** — так студенты ничего не увидят, пока вы не проверите.
3. Перетащите файлы в окно (или «Выбрать файлы»): видео, аудио, PDF, слайды, картинки, документы — всё вместе.
4. Проверьте названия (их можно поправить) и нажмите **«Загрузить и создать материалы»**.
5. Для каждого файла появится строка с ходом загрузки. Видео и аудио после загрузки проходят проверку и обработку на сервере — это занимает от нескольких секунд до нескольких минут.
6. Откройте материалы, проверьте их кнопкой **«Предпросмотр глазами студента»**, затем переведите в **«Опубликовано»**.

## Добавить один материал

**Материалы → «Добавить материал»**. Заполните только это:

| Поле | Что вписать |
|---|---|
| **Название материала** | как увидит студент |
| **Тип** | Видео, PDF, Конспект (текст), Аудио, Слайды, Изображение, Файл, Книга |
| **Предмет** | обязательно |
| **Тема** | по желанию |
| **Файл** (или **Текст конспекта**) | нажмите «Выбрать файл» |

Всё остальное спрятано в блоке **«Дополнительно (необязательно)»**: видимость (черновик / опубликовано / запланировано), дата публикации и порядок в теме. Обычно трогать его не нужно (по умолчанию — «Опубликовано»).

## Какие файлы принимаются

| Тип | Форматы | Максимум |
|---|---|---|
| Видео | mp4, m4v, mov, webm, mkv, avi | 150 МБ |
| Аудио | mp3, wav, m4a, aac, ogg, flac | 80 МБ |
| PDF | pdf | 25 МБ |
| Слайды | pdf, pptx | 40 МБ |
| Изображение | jpg, jpeg, png, webp | 5 МБ |
| Файл | pdf, txt, csv, docx, xlsx, pptx, zip | 25 МБ |

Видео в других форматах (mkv, mov, avi, webm) сервер **сам преобразует** в формат, который играет в любом браузере. Перед загрузкой видео лучше сжать до **720p** (обычно 1–2 ГБ в час → 0,7–1 ГБ в час): студентам хватает, а место на сервере экономится.
Файл с неподходящим расширением, подделанным типом (например, текст, переименованный в .mp4) или превышающий размер **не загрузится** — вы увидите понятное сообщение.

## Что означают статусы файла

| Что вы видите | Что это значит | Что делать |
|---|---|---|
| «В очереди на обработку» / «Обработка…» | сервер проверяет файл (антивирус, видео — ещё и преобразование) | подождать; студенты файл пока не видят |
| «Готово» | файл проверен и доступен | можно публиковать |
| «Файл отклонён» + причина | файл повреждён, нет видеодорожки, **найден вирус** и т. п. | загрузите другой файл |
| «Ошибка обработки» + причина | временная проблема (нет места на диске, хранилище или антивирус недоступны) | исправить причину и нажать **«Повторить обработку»**; многие случаи сервер повторит сам |

Сообщение «Антивирусная проверка сейчас недоступна» значит, что файл ждёт и проверится автоматически, когда сервис заработает. Если файл отклонён из-за вируса — студентам он не показывается никогда.

## Скрытые от студентов и запланированные материалы

* **Черновик** — виден только администраторам.
* **Запланировано** — выберите дату в блоке «Дополнительно»: материал появится сам.
* Заменили файл — прежний сохраняется в **истории версий** (можно восстановить).

## Что видит студент

Студент **не может скачать** оригинал: видео и PDF открываются во встроенном плеере/читалке с персональным водяным знаком. Это нормальное поведение, а не ошибка.

## Если что-то не получается

* «Файл слишком большой» — сожмите видео (HandBrake или любой конвертер, 720p).
* Видео долго «Обрабатывается» — нормально для длинных видео; можно загружать на ночь.
* «Нет прав на загрузку файлов» — войдите заново под администратором (с двухфакторным кодом).
* Всё остальное — сообщите, прислав **название файла и текст сообщения** (без паролей).
